# Hi, I'm saturnone1

## What I work on

- Local-first AI assistants and MCP integrations
- RAG services and document-grounded retrieval
- DDS-based distributed and real-time systems
- C#, .NET, TypeScript, Node.js, C++, CMake, and Python
